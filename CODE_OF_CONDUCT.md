# Code of Conduct

This project follows a simple standard: be respectful, be specific,
and keep discussion focused on the code and the evidence.

## Expected behaviour

- Critique code and claims, not people.
- Use synthetic data in examples and reproductions.
- Credit prior work accurately, including upstream authors.

## Unacceptable behaviour

- Harassment, discrimination, or personal attacks.
- Publishing private data, credentials, or non-public traffic details.
- Misrepresenting test results or upstream status.

Reports about conduct in this repository can be sent to
priyanshukumarthakur937@gmail.com. Reports will be reviewed and acted
on proportionately, including removing comments or closing issues and
pull requests that violate this code.
